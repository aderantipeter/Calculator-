# JavaScript Calculator

This is my first project using JavaScript.

It is a simple calculator that performs basic mathematical calculations.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Simple and easy-to-use interface

## How to Use

1. Open the calculator.
2. Enter the numbers you want to calculate.
3. Choose an operation.
4. View the result.
